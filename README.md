# SmartPlug

Open source for the SmartPlug Android application, ESP-07 firmware, and
ServerSmartPlug firmware.

## Repository layout

- `SmartPlug/` — Android application, ESP-07 firmware, design documentation,
  hardware evidence, and engineering documentation.
- `ServerSmartPlug/` — ESP32 server firmware used by the server integration
  mode.

> Safety notice: this repository contains engineering source and is not proof
> that a mains-connected product is safe, certified, or production-ready.
> Review the design and production-readiness documents before building or
> energizing any hardware.
